# Helical entry for adaptive clearing

FreeCAD 1.1.0 at commit `34a9716668b1ddeb55b914f1c5be644826bdbbbf` searches inward offsets of the tool-center region for an entry point. It checks the proposed center against exclusions, then tests the full disk of radius `helixRampRadius + toolRadius` against the cutting region. If the disk crosses a boundary, it searches another region. The accepted disk is also used to initialize its cleared-area model. Whittle implements its own TypeScript fit around validated cutting paths using this footprint test as the reference. [Pinned FreeCAD Adaptive2d source](https://github.com/FreeCAD/FreeCAD/blob/34a9716668b1ddeb55b914f1c5be644826bdbbbf/src/Mod/CAM/libarea/Adaptive.cpp#L1974)

In **Adaptive clearing**, choose **Entry → Helical ramp**. The orbit diameter refers to the diameter traced by the tool center. A blank diameter uses half the inherited cutter diameter. A blank maximum ramp angle uses 3°. The allowed angle range is 1–15°. Existing operations retain vertical plunge unless changed. The entry settings persist in `.cam`.

The planner checks the full orbit plus cutter radius against the original analytic sketch boundaries, including islands. It first tries the cut's existing start and checks alternate seams on closed cuts when necessary. Each separately linked cut gets a fitted ramp. The tool approaches the sketch plane or the prior pass depth vertically, descends in full turns with a pitch within the configured angle, and feeds to the cut start if needed. Between cuts it retracts and traverses at clearance unless [stock-aware linking](CAM_ADAPTIVE_LINKS.md) certifies a feed connector. If an entry cannot fit, generation reports the failed cut and leaves the entry choice with the user.

A descending semicircle uses the existing neutral arc motion with axial travel. Its center is in the start plane, its endpoints specify the pitch, and the preview renders and interpolates the descent. The existing planar APT-CL exporter reports helical moves as unsupported. Fit is checked against the sketch and uses a bounded seam search. Stock, fixture, shank, and holder collision checks are outside this workflow.
