# Adaptive clearing for concave pockets and islands

The reference is FreeCAD 1.1.0 at commit `34a9716668b1ddeb55b914f1c5be644826bdbbbf`. Its `ClearedArea::ExpandCleared` offsets completed tool-center paths with round ends by approximately the cutter radius, unions the footprints with previously cleared paths, and invalidates cached bounds. `CalcCutArea` tests successive cutter positions against that cleared region. The steering loop uses an area-per-distance target and classifies clear versus uncleared links. This implementation uses the technique as a reference and adds no FreeCAD source code or new dependency. [Pinned Adaptive2d source](https://github.com/FreeCAD/FreeCAD/blob/34a9716668b1ddeb55b914f1c5be644826bdbbbf/src/Mod/CAM/libarea/Adaptive.cpp)

Whittle reuses the existing cutter-compensated pocket offsets for concave sketches, disjoint regions, and nested islands. From inside out, it evaluates candidate loops against a Clipper2 union of completed tool sweeps. A polygonal cutter disk sampled along each candidate estimates exposed cutting area. The planner tries wider spacing where that estimate meets the target and the swept-region comparison shows that intermediate loops are covered within polygon tolerance. The original single-circle operation keeps its analytic disk model and arcs.

The engagement target is sampled and applies to qualifying clearing loops. Seed cuts and transitions that exceed the sampled target are counted in the preview so the user can identify operations with exceptions. Entry supports vertical plunge or a [fitted helical ramp](CAM_ADAPTIVE_HELIX.md). Cut loops reuse the existing neutral motion types, and separate loops use clearance by default. [Stock-aware linking](CAM_ADAPTIVE_LINKS.md) can keep the cutter down for checked connectors. Each depth uses the same XY plan and assumes uncleared material at that depth. The preview does not model real stock geometry, previous operations, the holder, or fixture collisions. General adaptive steering and pocket NC output remain outside this implementation.
