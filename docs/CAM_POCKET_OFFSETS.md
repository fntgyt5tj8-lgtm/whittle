# Concave pockets and islands in Whittle

The FreeCAD reference is 1.1.0 at commit `34a9716668b1ddeb55b914f1c5be644826bdbbbf`. PocketShape derives and combines removal faces, then the shared Area operation produces sections at cutting depths. The native offset strategy starts at the cutter radius and applies additional offsets by stepover. Its libarea adapter sends scaled polygons to Clipper and reconstructs and reorders the output loops. This lets offsets split, close narrow passages, and merge neighboring exclusions. [FreeCAD PocketShape](https://github.com/FreeCAD/FreeCAD/blob/34a9716668b1ddeb55b914f1c5be644826bdbbbf/src/Mod/CAM/Path/Op/PocketShape.py) · [Native Area](https://github.com/FreeCAD/FreeCAD/blob/34a9716668b1ddeb55b914f1c5be644826bdbbbf/src/Mod/CAM/App/Area.cpp) · [libarea adapter](https://github.com/FreeCAD/FreeCAD/blob/34a9716668b1ddeb55b914f1c5be644826bdbbbf/src/Mod/CAM/libarea/AreaClipper.cpp)

Whittle groups one sketch into closed loops and uses even-odd fill, so winding and selection order do not determine what gets cut. An outer loop defines a pocket, a loop inside it defines an island, and a loop inside an island defines another pocket. Closed disjoint outer loops in the same sketch are also supported. Crossing, touching, and ambiguous boundaries are rejected. The existing analytic circle and convex-polygon strategies still handle those single-loop cases.

For complex pockets, pinned `clipper2-ts` 2.0.1-19 produces nested cutter-center offsets inside-out. Outer walls shrink, island exclusions expand, and necks narrower than the cutter can split into separate cutting regions. Whittle checks the generated lines against the original sketch curves for cutter-radius clearance. Complex curves are polygonized at a nominal 0.001 mm chord tolerance and the compensation includes a small margin for tessellation, rounding, and the integer grid. Complex cuts emit neutral lines, while the single-circle strategy keeps its analytic arcs. FreeCAD's LGPL orchestration remains a source reference. The separate Clipper2 TypeScript port is Boost Software License 1.0 and its notice ships with the web build. [Clipper2 TypeScript port](https://github.com/countertype/clipper2-ts)

Depth scheduling, tool assignment, and `.cam` settings are shared with the existing operation. Separate loops feed vertically down and retract to the configured clearance before repositioning, including between loops at the same depth. This can add travel compared with stock-aware linking. The user must select a plunge-capable cutter and clearance suitable for the stock and fixtures. Pocket NC export and full tool assembly collision checking are outside this increment.
